# integrator-lib

`integrator-lib` provides coordinate-independent time integration methods for
array-valued and compound states. The numerical methods accept right-hand-side
or step callables and do not depend on a particular spatial representation or
quantum-dynamics model.

The public API contains:

- `RK4`: classical four-stage, fourth-order Runge--Kutta integration.
- `IMCMF1`: first-order implicit-midpoint propagation with a frozen
  state-dependent operator.
- `IMCMF2`: second-order predictor-corrector implicit-midpoint propagation
  with a predicted midpoint-frozen operator.
- `CrankNicolson`: matrix-free implicit midpoint/Crank--Nicolson integration
  using SciPy GMRES or BiCGSTAB, with optional preconditioning.
- `ShortIterativeLanczos`: short-iterative Lanczos (SIL) exponential actions
  generated by a Hermitian Hamiltonian, including real- and imaginary-time
  propagation.
- `ArnoldiExponential`: short-iterative Arnoldi (SIA) propagation for a
  general, possibly non-Hermitian linear generator.
- `Strang2`: second-order symmetric `A/2 - B - A/2` composition.
- `LinearSolveError`: raised when an iterative Crank--Nicolson solve fails.
- `KrylovConvergenceError`: raised when exponential propagation does not
  converge after its configured step refinements.

Install from a local checkout:

```bash
python -m pip install .

```

## Usage

```python
from integrator_lib import IMCMF1, IMCMF2, CrankNicolson, RK4, Strang2

integrator = Strang2(
    linear_integrator=CrankNicolson(
        solver="gmres",
        rtol=1e-11,
        preconditioner=preconditioner,
    ),
    nonlinear_integrator=RK4(),
)

new_state = integrator(
    state,
    time,
    time_step,
    linear_rhs,
    nonlinear_rhs,
)
```

Every right-hand side returns a time derivative. For an equation written as
`i dy/dt = H(t)y`, the corresponding callable returns `-1j * H(t)y`.

For imaginary-time propagation, `dstate/dtau = -H state`, pass a real-valued
right-hand side returning `-H(state)`. `CrankNicolson` then applies

```text
(I + dt H / 2) state_new = (I - dt H / 2) state
```

without promoting a real state to complex arithmetic. Normalization and
ground-state convergence criteria belong to the calling application rather
than the generic time integrator.

`Strang2` treats its state as an opaque object. Its component steppers may
therefore evolve a NumPy array or a compound state containing several coupled
variables.

## Constant-mean-field propagation

`IMCMF1` and `IMCMF2` receive a callback that separates construction of a
state-dependent operator from its linear action:

```python
def freeze(reference_state):
    frozen_data = build_operator_data(reference_state)

    def linear_rhs(trial_state, time):
        return apply_frozen_operator(frozen_data, trial_state, time)

    return linear_rhs
```

`IMCMF1` freezes at the beginning of each interval and performs one
implicit-midpoint step. `IMCMF2` takes one predictor half-step, freezes at the
predicted midpoint, and then restarts from the initial state. The corrector
may use one whole step or two half-steps:

```python
integrator = IMCMF2(
    predictor_integrator,
    corrector_integrator,
    corrector_steps=2,
)
new_state = integrator(state, time, time_step, freeze)
```

Separate predictor and corrector integrators allow their preconditioners to
match their respective step sizes. Krylov iteration counts and residual norms
are recorded separately for the predictor and corrector steps.

## Krylov exponential propagation

`ShortIterativeLanczos` and `ArnoldiExponential` approximate a matrix
exponential without constructing the matrix. Both use the standard integrator
call signature:

```python
new_state = integrator(state, time, time_step, linear_rhs)
```

`ShortIterativeLanczos` is intended for exponentials generated by a Hermitian
Hamiltonian. For real-time TDSE propagation, the supplied callable follows the
same convention as `CrankNicolson` and returns the time derivative:

```python
def linear_rhs(state, time):
    return -1j * apply_hamiltonian(state, time)

integrator = ShortIterativeLanczos(
    max_krylov_dimension=20,
    rtol=1e-10,
    max_refinements=8,
    reorthogonalize=True,
)
```

The default `generator_factor=-1j` tells SIL that the derivative is
`-1j * H @ state`. Imaginary-time filtering uses the same Hermitian Lanczos
projection with a real generator:

```python
integrator = ShortIterativeLanczos(
    generator_factor=-1.0,
    max_krylov_dimension=20,
    rtol=1e-10,
)

def imaginary_time_rhs(state, imaginary_time):
    return -apply_hamiltonian(state, imaginary_time)

filtered_state = integrator(
    state,
    imaginary_time,
    imaginary_time_step,
    imaginary_time_rhs,
)
```

`generator_factor` and `linear_rhs` must describe the same generator. The
calling application remains responsible for normalizing the filtered state,
testing ground-state convergence, and selecting the requested symmetry sector.
`ArnoldiExponential` can also evaluate the imaginary-time action directly from
`linear_rhs = -H`, but Lanczos is the more economical projection when the
Hamiltonian is Hermitian.

`ArnoldiExponential` accepts a general linear generator and is therefore the
appropriate choice when, for example, a complex absorbing potential makes the
Hamiltonian non-Hermitian:

```python
integrator = ArnoldiExponential(
    max_krylov_dimension=30,
    rtol=1e-10,
    max_refinements=8,
)
```

Each operator is sampled at the temporal midpoint. If the endpoint Krylov
residual estimate does not satisfy the requested tolerance at the maximum
Krylov dimension, the interval is bisected recursively. The refinement limit
applies to one user-requested time step; it is not a replacement for a
time-discretization error controller. The requested tolerance is divided among
refined substeps so their estimated errors remain bounded over the original
user-requested interval.

A representation-specific inner product can be supplied without exposing its
weights to the integrator:

```python
integrator = ShortIterativeLanczos(
    inner_product=representation.inner_product,
)
```

An optional batched callback reduces orthogonalization synchronization for
distributed representations:

```python
integrator = ShortIterativeLanczos(
    inner_product=representation.inner_product,
    inner_products=representation.inner_products,
)
```

`inner_products(left_vectors, right)` returns one inner product for every left
vector. When omitted, the scalar `inner_product` callback is used separately
for every vector. The linear-combination work array is reused while expanding
one Krylov subspace.

The most recent call records diagnostics in `last_attempts`. Aggregate values
are also available as:

- `last_operator_calls`
- `last_accepted_substeps`
- `last_rejected_substeps`
- `last_refinement_depth`
- `last_krylov_dimension`
- `last_error_estimate`

`last_error_estimate` is the sum of the residual-based estimates for the
accepted substeps. Detailed accepted and rejected attempts, including their
individual tolerances and refinement depths, remain available in
`last_attempts`.

Step refinement controls Krylov projection error. For a genuinely
time-dependent operator, midpoint sampling still gives a second-order temporal
approximation, and the calling application remains responsible for selecting
or controlling the physical time-step error.
